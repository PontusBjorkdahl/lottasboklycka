# Lottas boklycka

Författarsida för Lotta Björkdahl och Fis-Orvar och de magiska fröna.

Statisk hemsida med HTML, CSS, JavaScript, illustrationer och två ljudklipp.

## GitHub Pages

Aktivera Settings → Pages → Deploy from a branch → main → /(root).

Kontaktformuläret kopierar ett meddelande; det skickar ännu ingen e-post.
